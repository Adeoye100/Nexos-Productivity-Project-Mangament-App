# Agent Instructions

## Strict Syntax & Style Rules

### No Emojis Rule (Persistent & Mandatory)
- **NEVER** use emojis anywhere in the codebase syntax, UI labels, text strings, console outputs, comments, markdown, documentation, or commit messages.
- For UI iconography, always use standard SVG / Lucide React icon components (`lucide-react`) rather than Unicode emojis.
- For text notifications and system feedback, use clean plain text without emoji prefixes or suffixes.
